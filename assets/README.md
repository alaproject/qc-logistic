# Assets

Folder ini disiapkan untuk logo perusahaan dan aset visual berikutnya.

Saat ini belum ada logo resmi. Template PDF memakai placeholder teks `QC`, sedangkan interface memakai Google Material Icons Round.

Folder ini juga dapat berisi artefak hasil download browser, seperti PDF manifes dan backup JSON. Pada workspace development saat ini lokasi download browser diarahkan ke folder ini, tetapi perilaku tersebut bergantung pada konfigurasi browser dan bukan kemampuan JavaScript untuk memilih folder secara bebas.

Asset yang dapat ditambahkan berikutnya:

- `logo.png` atau `logo.svg` untuk header aplikasi dan manifes.
- Ikon armada atau brand tambahan jika diperlukan.
- Stempel/verifikasi resmi untuk dokumen PDF.
